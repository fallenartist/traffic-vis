# Analiza ruchu w Gliwicach

Interaktywna mapa przepływów samochodów, autobusów, rowerów i pieszych między punktami w Gliwicach. Kolory oznaczają rodzaj transportu, a wielkość przepływu odpowiada natężeniu ruchu.

Dostępne widoki:

- **3D** — wstęgi Sankeya przedstawiające kierunki i wielkość przepływów.
- **2D** — chmury punktów, których zagęszczenie obrazuje natężenie ruchu.

Panel boczny pozwala wybierać rodzaj transportu i lokalizację, porównywać napływ z odpływem oraz eksportować dane.

Punkty na mapie są przyblione, dane są przykładowe i nie pochodzą z rzeczywistych pomiarów.
